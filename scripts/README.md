# Linux Log Analyzer

A beginner-friendly Linux log analysis tool built using Bash scripting in Ubuntu WSL.

## Project Overview

The Linux Log Analyzer is a practical Linux administration project designed to search, analyze, and count different log levels using Bash and standard Linux commands.

## Features

- Search for INFO messages.
- Identify WARNING messages.
- Find ERROR messages.
- Count log entries by severity.
- Generate a basic terminal summary report.

## Technologies Used

- Ubuntu Linux (WSL)
- Bash Scripting
- Linux Commands
- Git
- GitHub

## How to Run

Clone the repository:

bash
git clone https://github.com/mandalarun683-pixel/Linux-Log-Analyzer.git

Navigate into the project:

bash
cd Linux-Log-Analyzer/scripts


Give execution permission:

bash
chmod +x log-analyzer.sh


Run the analyzer:

bash
./log-analyzer.sh
